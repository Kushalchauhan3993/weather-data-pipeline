# Reports Directory
This folder contains auto-generated weather reports.

Files generated here:
- daily_YYYY-MM-DD.txt   — plain text daily report
- daily_YYYY-MM-DD.json  — machine readable daily report
- daily_YYYY-MM-DD.html  — visual HTML daily report
- analytics_report.txt   — answers to all 5 analysis questions

To generate reports run:
    python main.py report
